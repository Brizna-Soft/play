Quadium 4004 Workbench

Juego de PC · Indie, Simuladores, Educación · Indie, Simulación

Aprende cómo funciona realmente un microprocesador programando, depurando y experimentando con el Intel 4004, el primer microprocesador comercial de la historia. Un completo entorno de desarrollo y aprendizaje con periféricos virtuales, lecciones integradas y soporte para hardware USB real.

De qué trata

Programa el Microprocesador que lo Inició Todo
Aprende cómo funciona realmente un microprocesador programando, depurando y experimentando con el Intel 4004, el primer microprocesador comercial de la historia.
Quadium 4004 Workbench combina un completo entorno de desarrollo con una plataforma de aprendizaje integrada, permitiéndote crear software, inspeccionar la ejecución del microprocesador en tiempo real, interactuar con periféricos virtuales e incluso comunicarte con dispositivos reales mediante USB.
Diseñado para aprender, experimentar y desarrollar. Quadium es un software educativo de ingeniería, no un videojuego tradicional.
Programa
Crea tus propios programas para el Intel 4004 utilizando un entorno de trabajo integrado con múltiples ventanas.
• Ensamblador Intel 4004

• QuadBasic (traducido a código máquina nativo del Intel 4004)

• Editor integrado

• Espacio de trabajo configurable

Depura
Observa exactamente qué ocurre dentro del microprocesador mientras se ejecuta tu código.
• Ejecución paso a paso

• Puntos de interrupción

• Registros en tiempo real

• Inspección de RAM y ROM

• Visualizador de pila

• Traza de ejecución

Experimenta
Observa cómo tus programas interactúan con el hardware en tiempo real mediante una colección de periféricos virtuales.
• LEDs

• Displays de siete segmentos

• Pantallas LCD

• Matriz de LEDs

• Teclado e interruptores

• Impresora

• Generador de onda cuadrada

• Dispositivos de memoria

Conecta Hardware Real
Ve más allá de la simulación comunicándote con dispositivos compatibles con Arduino mediante USB y permite que los programas que se ejecutan en el Intel 4004 interactúen con electrónica real.

Requisitos

Mínimos

• Requiere un procesador y un sistema operativo de 64 bits

• SO: Windows 10/11 (64-bit)

• Procesador: 64-bit CPU, 1.6 GHz dual-core

• Memoria: 4 GB de RAM

• Gráficos: 1280×1080 display; integrated graphics sufficient

• DirectX: Versión 9.0c

• Almacenamiento: 250 MB de espacio disponible

• Notas adicionales: 64-bit Windows only. Minimum desktop working area 1024×720

Recomendados

• Requiere un procesador y un sistema operativo de 64 bits

• SO: Windows 11 64-bit

• Procesador: 64-bit CPU, 2.0 GHz dual-core or better

• Memoria: 4 GB de RAM

• Gráficos: 1920×1080 display

• DirectX: Versión 9.0c

• Almacenamiento: 500 MB de espacio disponible

• Notas adicionales: Multiple floating module windows and VDP-style graphics benefit from 1920×1080

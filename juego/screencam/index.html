ScreenCam

Juego de PC · Producción de vídeo

ScreenCam es una herramienta de grabación de pantalla. Permite capturar el gameplay, el escritorio y ventanas individuales con alta calidad de imagen y una carga mínima en el sistema. Admite codificación por hardware para un funcionamiento estable incluso durante tareas que consumen muchos recursos.

De qué trata

ScreenCam es un grabador de pantalla rápido y práctico, con una interfaz sencilla y amplias opciones de personalización.
MODOS DE GRABACIÓN
• Pantalla completa
Captura todo el escritorio. Ideal para grabar flujos de trabajo, streams y cualquier actividad en pantalla.

• Región
Selecciona un área rectangular arbitraria de la pantalla. Útil cuando solo se necesita grabar una parte de la interfaz o un fragmento concreto.

• Ventana
Graba una ventana de aplicación seleccionada. El resto del contenido de la pantalla queda fuera del vídeo.

• Game Mode
Modo optimizado para juegos. Proporciona una captura estable con una carga mínima del sistema y altas frecuencias de imagen, incluso en proyectos exigentes.

• Device Mode
Grabación desde dispositivos de captura: webcams, tarjetas de captura y otras fuentes.

FUNCIONES
• Separación y mezcla de pistas de audio (sonido del sistema + micrófono) con control de volumen independiente;

• Grabación en directo con superposición de webcam;

• Codificación por hardware: NVIDIA, Intel, AMD;

• Ajustes flexibles de calidad, FPS, bitrate y resolución.

Requisitos

Mínimos

• Requiere un procesador y un sistema operativo de 64 bits

• SO: Windows 10 1803 64-bit (build 17134) or newer

• Procesador: 64-bit (x86_64) dual-core, Intel Core i3 / AMD FX or better

• Memoria: 8 GB de RAM

• Gráficos: Any DirectX 11 GPU / iGPU with Feature Level 11_0 and current driver (CPU encoding via OpenH264)

• DirectX: Versión 11

• Almacenamiento: 1 GB de espacio disponible

• Tarjeta de sonido: Any WASAPI-compatible onboard audio (e.g. Realtek). No Stereo Mix needed

• Notas adicionales: WebView2 Evergreen Runtime required. 64-bit Windows only

Recomendados

• Requiere un procesador y un sistema operativo de 64 bits

• SO: Windows 10 2004+ / Windows 11 64-bit

• Procesador: Quad-core+, Intel Core i5 8th Gen+ / AMD Ryzen 5+

• Memoria: 8 GB de RAM

• Gráficos: NVIDIA GTX 10xx+ (NVENC) / AMD RX 5xx+ (AMF) / Intel UHD 630+ (QSV) with current driver for 1080p60+ hardware encoding

• DirectX: Versión 11

• Almacenamiento: 1 GB de espacio disponible

• Tarjeta de sonido: Any WASAPI-compatible audio

• Notas adicionales: 120 fps requires NVIDIA/AMD (Intel QSV capped at 60 fps). 4K60 wants discrete GPU + 16 GB RAM + SSD

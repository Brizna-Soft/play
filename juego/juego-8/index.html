Requisitos

Mínimos

• Requiere un procesador y un sistema operativo de 64 bits

• SO *: Windows 7/10/11 64-bit

• Procesador: 1.8 GHz Intel Core 2 Duo / AMD Athlon 64 X2 或同等处理器

• Memoria: 2 GB de RAM

• Gráficos: DirectX 9.0c，256 MB

• DirectX: Versión 9.0c

• Almacenamiento: 1 GB de espacio disponible

• Tarjeta de sonido: 兼容 DirectX 9.0c

• Compatibilidad con RV: 不支持

• Notas adicionales: 不支持32位操作系统；建议使用16:9分辨率显示器
